Phase 10 backend gate: `backend/test_phase10_backend_verify.py` (14 cases). Full `pytest backend/` = 79 passed.

- **AudioLevelEvent / TTS** (`tts.speak_and_play`): patch `tts._convert` (async → known PCM bytes), `tts._play_pcm_block_sync` (no-op), and `tts.hub` (FakeHub capturing broadcasts). Assert every broadcast is an `AudioLevelEvent`, all 0.0≤level≤1.0, LAST==0.0. The level=0.0 settle is in a `finally` block — make `_play_pcm_block_sync` raise to prove the finally still fires (PCM still returned). `_rms_level(samples)`: empty/silence→0.0, constant 32767→~1.0, >fullscale clips to 1.0. Build multi-block PCM via `int(PCM_SAMPLE_RATE*AUDIO_LEVEL_INTERVAL_S)` (= 800 samples/block).
- **Crash recovery** (`pipeline._run_turn`/`_handle_turn_crash`): patch `pipeline_mod.asyncio.sleep` to no-op (the CRASH_RECOVERY_DELAY_S wait). After `MAX_TURN_RETRIES`(=3) consecutive crashes → `state=="error"`, `_consecutive_crashes==3`, recovery stops. Reset path: drive real `_run_turn` with stubbed `record_until_silence`/`stt.transcribe` (raise twice then return) + stubbed `_respond_with_interrupt`; a clean turn resets counter to 0. Set `pipe._running=True` manually (no start()).
- **Graceful degradation** (`pipeline._iter_reply`): inject `claude=`/`ollama=` fakes. Claude raising `MissingCredentialError` OR `ClaudeAPIError` *before any yield* → Ollama tokens used (`claude_fallback_to_ollama`). Claude yielding 1 token THEN raising → Ollama NOT called (the `produced_any` guard; restarting would duplicate the spoken prefix). See [[phase9-testing]] for the original wiring note.
- **Agent rename endpoint** (`main.rename_agent_endpoint`, POST `/api/agents/{id}/rename`): test with a plain `TestClient(main.app)` NOT used as a context manager — entering the `with` runs the full lifespan which OVERWRITES `app.state.agents` with the real runtime roster (and starts voice/Slack/Gmail). Seed `main.app.state.agents={"backend": SimpleNamespace(id,name,status,_current_task_label)}`, then `monkeypatch.setattr(main, "rename_agent", AsyncMock(return_value=True))` (the DB write is imported into main's namespace) and `monkeypatch.setattr(main.hub, "broadcast", AsyncMock())`. Validation: 200 trims name + mutates live `agent.name` + awaits rename once + broadcasts one `AgentUpdate`; 404 unknown (no write/broadcast); 400 empty-after-strip and 400 >50 chars (MAX_AGENT_NAME_LEN, boundary 50 passes). Suite `backend/test_phase10_rename_verify.py` (6 cases) → full `pytest backend/` = 85 passed.
- **Setup wizard** (`backend/setup_wizard.py`): do NOT spin up the full `backend.main.app` (its lifespan inits DB/vector-store/agents/voice/Slack/Gmail — heavy). The /setup/* endpoints touch ONLY the keystore. Mount just the router on a fresh `FastAPI()` and monkeypatch `setup_wizard.keystore.has_credential` + `setup_wizard.keystore._set` to an in-memory dict. 7 REQUIRED_CREDENTIALS (anthropic/elevenlabs key+voice/slack_bot/gmail id+secret+refresh). Unknown name → 400; value never echoed (json.dumps the body, assert secret absent). Router is mounted in main.py via `app.include_router(setup_router)`.
